# Adrenaline Archived

This directory contains versions of Adrenaline that are no longer officially supported and out of our release cycle. Pack authors may use these if they are in a situation where Adrenaline does not currently support their required version.

As these versions are unsupported, _do not_ ask for support using these versions. You will likely be ignored.

---

These versions may be updated by contributors through [Pull Requests](https://github.com/skywardmc/adrenaline/pulls) if needed.

If you are a contributor updating these archived versions, please change the version number to the current date when doing so. For the format, use ISO 8601 Basic. (`YYYYMMDD`, for example: `archived.20260725+mc1.19.2.fabric`)

Do note that updated versions will not be released to Modrinth.
